# Etch-a-Sketch

A browser-based drawing application built with **HTML**, **CSS**, and **JavaScript** as part of **The Odin Project** Foundations curriculum.

## Overview

This project recreates a simple digital version of the classic Etch-a-Sketch toy. Users can generate a customizable grid and draw by moving their mouse over the squares, which change color on hover.

The project focuses on developing JavaScript DOM manipulation skills, event handling, dynamic element creation, and user input validation.

## Features

* Dynamic grid generation
* Adjustable grid sizes from **16×16** up to **100×100**
* Hover-to-draw functionality
* Input validation for grid dimensions
* Responsive square cells using CSS Flexbox
* Custom Etch-a-Sketch-inspired styling

## How It Works

1. The page loads with a default **16×16** grid.
2. Users enter a number between **16 and 100**.
3. Clicking **Create New Grid** generates a new grid with the specified dimensions.
4. Moving the mouse over squares changes their color, creating a drawing effect.

## Installation

Clone the repository:

```bash

```

Navigate to the project folder:

```bash
cd etch-a-sketch
```

Open `etch-a-sketch.html` in your preferred web browser.
